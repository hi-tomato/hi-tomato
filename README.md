### 만든 것

- **Kiply** — 다중 체인 비수탁 지갑 (React Native/Expo) · 소셜 로그인 4종 / PIN / 생체 인증 · 토큰 송금
- **운영 백오피스** — 어드민·파트너 이중 역할 관리 웹 (React 19 · Vite)
- **브랜드 웹사이트** — 다국어 랜딩 + 파트너 연동 (Next.js App Router)
- **네이티브 모듈** — Argon2id 봉투 암호화 (Kotlin·Swift 직접 구현)

### 일하는 방식

- 캐시 스코프 누락은 타입으로, 보안 경로 회귀는 커버리지 잠금으로 — 사람 대신 도구로 강제합니다
- 테스트 1,681개와 CI·OTA 파이프라인으로 혼자서도 무너지지 않는 배포를 유지합니다
- 실무 코드는 회사 저장소(비공개)에 있습니다 — 잔디와 아래 카드가 그 기록입니다
