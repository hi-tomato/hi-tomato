**React Native와 Next.js로 모바일과 웹을 함께 만드는 프론트엔드 개발자입니다.**
금액과 인증처럼, 틀리면 사용자가 다치는 경계를 코드로 막는 데 집중합니다.

- 앱과 웹의 경계 없이 일합니다 — RN(Expo) 앱, React SPA, Next.js 웹을 각각 단독으로 완성해 봤습니다
- JS로 부족하면 내려갑니다 — Kotlin·Swift 네이티브 모듈(Argon2id 봉투 암호화)을 직접 작성합니다
- 서버 상태를 설계합니다 — 도메인별 캐시 수명 분리, 토큰 갱신 single-flight, 낙관적 업데이트
- 혼자서도 무너지지 않게 만듭니다 — 테스트 1,681개, 커버리지 잠금, CI·OTA 파이프라인
